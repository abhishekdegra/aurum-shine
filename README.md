## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/abhishekdegra/detailing-rebels.git

# Navigate to project folder
cd detailing-rebels

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build
```bash
npm run build
npm run preview
```

---

## ☁️ Deployment on Vercel

1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com/) and click **"Add New Project"**.
3. Import `abhishekdegra/detailing-rebels`.
4. Vercel will automatically detect **Vite** as the framework.
5. Click **"Deploy"**. The site will be live within 30 seconds with automatic SSL and CDN distribution.
